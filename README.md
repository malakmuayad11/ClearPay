# ClearPay – Smart Payment Management

A modern, responsive fintech website designed to simplify payment management and provide a transparent pricing experience.

## 🌐 Live Demo

[View ClearPay Website](https://malakmuayad11.github.io/ClearPay)

## 📖 Overview

ClearPay is a fintech website concept focused on making payment management simpler, more transparent, and accessible. It provides users with an overview of payment solutions, pricing plans, and features through a clean and user-friendly interface.

The project focuses on responsive web design, reusable components, and interactive JavaScript functionality.

## ✨ Features

- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile devices.
- **Home Page:** Introduces ClearPay and its core value proposition.
- **About Page:** Presents the company's story, mission, and values.
- **Features Page:** Showcases available features with interactive category filters.
- **Pricing Page:** Includes pricing plans and an interactive pricing calculator.
- **Contact Page:** Provides contact information and a form with client-side validation.
- **Dynamic Components:** Shared header and footer loaded across multiple pages.
- **Theme Support:** Consistent styling and reusable design variables.
- **Performance Optimization:** Responsive images, modern image formats, and optimized loading.

## 🛠️ Technologies Used

- **HTML5** – Semantic page structure.
- **CSS3** – Responsive layouts, Flexbox, CSS Grid, animations, and custom properties.
- **JavaScript (ES6+)** – DOM manipulation, event handling, form validation, and interactive functionality.
- **Google Fonts (Inter)** – Typography.
